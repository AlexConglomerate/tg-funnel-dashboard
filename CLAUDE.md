# tg-funnel-dashboard

Telegram-бот с воронкой регистрации + дашборд в Mini App. Спека и все решения: `docs/spec.md`. Сначала спека, потом код.

## Команды
- `uv sync`: зависимости (Python 3.12 через uv, системный Python не трогаем)
- `./scripts/dev.sh`: полный локальный запуск (туннели + бот)
- `uv run python -m funnel`: запуск без туннеля
- Проверки, должны быть зелёными перед сдачей: `uv run pytest && uv run mypy src tests && uv run ruff check && uv run ruff format --check .`

## Соглашения
- У функций с параметрами больше одного все параметры передаются по имени: `def f(*, a: int, b: str)`.
- Везде подсказки типов, `mypy --strict` без ошибок.
- Логика воронки живёт в `registration.py` без aiogram, `bot.py` только переводит апдейты в её вызовы.
- Время в базе всегда UTC в формате `db.to_db()`: строки сравниваются как время.
- Тексты в YAML, не в коде. Количество followups в коде не зашито.
- Шаги воронки логируются на INFO, ошибки на ERROR (уровень ERROR уходит алертом админам).

## Нельзя
- `git commit`, `git push`, создание репозитория: это делает автор.
- Показывать или коммитить `.env` и `private/`.
